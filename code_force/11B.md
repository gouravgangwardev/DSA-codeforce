## 1. B. Jumping Jack

### Approach
After `n` jumps, the maximum distance Jack can reach is:

\[
S = \frac{n(n+1)}{2}
\]

Jack can change the direction of any jump. Changing a jump from right to left changes the final position by `2 × jump`.

Therefore, we need:

- `S >= |x|`
- `(S - |x|)` must be even

Keep increasing `n` until both conditions are satisfied.

### Complexity
- Time: `O(√|x|)`
- Space: `O(1)`

## solution
```
#include <bits/stdc++.h>
using namespace std;
 
int main() {
    long long x;
    cin >> x;
 
    x = abs(x);
 
    long long n = 0;
    long long sum = 0;
 
    while (sum < x || (sum - x) % 2 != 0) {
        n++;
        sum += n;
    }
 
    cout << n << '\n';
 
    return 0;
}
```
