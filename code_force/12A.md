## 3. A. Super Agent

### Approach
The `3 × 3` keyboard must be symmetric around its center.

A cell `(i,j)` must be equal to the cell obtained after a `180°` rotation:

\[
(i,j) \rightarrow (2-i,2-j)
\]

Check every pair. If any pair differs, print `NO`; otherwise print `YES`.

### Complexity
- Time: `O(1)`
- Space: `O(1)`

### Key Pattern
**Super Agent → 180° rotation → compare opposite cells.**
## Solution
```
#include <bits/stdc++.h>
using namespace std;
 
int main() {
    char a[3][3];
 
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++)
            cin >> a[i][j];
 
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            if (a[i][j] != a[2 - i][2 - j]) {
                cout << "NO\n";
                return 0;
            }
        }
    }
 
    cout << "YES\n";
    return 0;
}
```
