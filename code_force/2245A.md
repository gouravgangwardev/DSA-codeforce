# 2. Who Watches the Watchpig?
## Problem

There are `n` piggies standing in a line.

A watchpig pair `(x,y)` exists when:

* `x < y`
* piggy `x` faces right
* piggy `y` faces left

Every piggy must belong to at least `k` watchpig pairs.

We may flip the direction of any piggy.

Find the minimum number of flips required, or print `-1` if it is impossible.

## Key Observation

A piggy can only belong to a watchpig pair in two ways.

### Piggy facing Right

If piggy `i` faces right, it needs at least `k` left-facing piggies to its right.

Therefore the first `k` positions cannot face left.

So:

`positions 1...k must be R`

### Piggy facing Left

If piggy `i` faces left, it needs at least `k` right-facing piggies to its left.

Therefore the last `k` positions cannot face right.

So:

`positions n-k+1...n must be L`

Thus the required final structure is:

`RRR...R [anything] LLL...L`

with `k` `R`s at the beginning and `k` `L`s at the end.

## Impossible Case

The first `k` positions must be `R`.

The last `k` positions must be `L`.

If:

`2k > n`

these two required regions overlap.

A position would need to be both `R` and `L`.

Therefore:

`2k > n -> -1`

## Minimum Flips

Only the forced regions matter.

For the first `k` positions:

* Every `L` must be flipped to `R`.

For the last `k` positions:

* Every `R` must be flipped to `L`.

Therefore:

`answer = number of L in first k positions + number of R in last k positions`

The middle positions can remain unchanged.

## Example

Consider:

`n = 6, k = 2`

`s = RLLRRL`

The first `2` positions must be:

`RR`

Current:

`RL`

So flip position `2`.

The last `2` positions must be:

`LL`

Current:

`RL`

So flip position `5`.

Final:

`RRLRLL`

Total flips:

`2`

## Algorithm

1. If `2*k > n`, print `-1`.
2. Count `L` among the first `k` positions.
3. Count `R` among the last `k` positions.
4. Add both counts.
5. Print the result.

## Complexity

* Time: `O(n)`
* Space: `O(1)`

## Code
```
#include<bits/stdc++.h>
using namespace std;
int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);
int t;
cin>>t;
while(t--){
int n,k;
string s;
cin>>n>>k>>s;
if(2*k>n){
cout<<-1<<'\n';
continue;
}
int flips=0;
for(int i=0;i<k;i++)
if(s[i]=='L')flips++;
for(int i=n-k;i<n;i++)
if(s[i]=='R')flips++;
cout<<flips<<'\n';
}
return 0;
}
```
