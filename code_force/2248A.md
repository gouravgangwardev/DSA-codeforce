# 5. You Delete, I Delete

## Problem

Alice and Bob are given a binary string `s`.

The game proceeds in two steps:

1. Alice deletes one `0`.
2. Bob deletes one `1`.

Alice wants the final string to be lexicographically largest.

Bob wants the final string to be lexicographically smallest.

Determine the final string when both play optimally.

## Key Observation

Alice wants to maximize the string.

For a binary string, deleting an earlier `0` is always better than deleting a later `0`.

Therefore Alice deletes the first `0`.

After Alice's move, Bob wants to minimize the resulting string.

Therefore Bob deletes the first `1`.

## Algorithm

1. Find the first `0` and remove it.
2. Find the first `1` in the resulting string and remove it.
3. Print the remaining string.

## Example

For:

`11001`

Alice deletes the first `0`:

`1101`

Bob deletes the first `1`:

`101`

Therefore the answer is:

`101`

## Complexity

- Time: `O(n)`
- Space: `O(n)`

## Code
```
#include<bits/stdc++.h>
using namespace std;
int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);
int t;
cin>>t;
while(t--){
string s;
cin>>s;
bool z=false,o=false;
for(char c:s){
if(c=='0'&&!z){
z=true;
continue;
}
if(c=='1'&&!o){
o=true;
continue;
}
cout<<c;
}
cout<<'\n';
}
}
```
