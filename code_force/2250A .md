## Problem 

There are `n` positions containing elements with weights `w[i]`.

Choose an integer `k`.

Each element moves:

- `w[i] < k` → moves left
- `w[i] > k` → moves right
- `w[i] = k` → movement fails

Determine whether there exists a perfect integer `k` such that after movement every position from `1` to `n` contains exactly one element.

## Key Observation

For every position to remain occupied:

- Position `1` must receive an element from position `2`.
- Position `2` must receive an element from position `1`.
- Position `3` must receive an element from position `4`.
- Position `4` must receive an element from position `3`.

Therefore the movement must be:

`1 <-> 2, 3 <-> 4, 5 <-> 6, ...`

Hence `n` must be even.

For odd positions, the element must move right:

`w[odd] > k`

For even positions, the element must move left:

`w[even] < k`

Therefore:

`max(w[even]) < k < min(w[odd])`

An integer `k` exists if:

`maxEven + 1 < minOdd`\

## Algorithm

1. If `n` is odd, print `NO`.
2. Find the maximum weight at even positions.
3. Find the minimum weight at odd positions.
4. Check whether:
   `maxEven + 1 < minOdd`
5. Print `YES` if an integer `k` exists.
6. Otherwise print `NO`.

## Complexity

- Time: `O(n)`
- Space: `O(1)`

## Code
```
#include<bits/stdc++.h>
using namespace std;
int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);
int t;
cin>>t;
while(t--){
int n;
cin>>n;
long long l=0,r=1e18;
for(int i=1;i<=n;i++){
long long x;
cin>>x;
if(i%2)r=min(r,x);
else l=max(l,x);
}
cout<<(n%2==0&&l+2<=r?"YES\n":"NO\n");
}
}return 0;
}
