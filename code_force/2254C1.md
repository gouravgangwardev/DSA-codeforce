# 3. Marenol — Easy Version

## Problem

You are given two binary strings `a` and `b`.

The allowed operations are:

`001 <-> 100`

and

`110 <-> 011`

Determine whether `a` can be transformed into `b`.

## Key Observation

Each operation moves one character by exactly two positions.

For example:

`001 -> 100`

The `1` moves from position `3` to position `1`.

Similarly:

`110 -> 011`

The `1` moves from position `1` to position `3`.

Therefore the parity of every `1` position never changes.

A `1` at an odd position can only move to another odd position.

A `1` at an even position can only move to another even position.

Therefore we only need to compare the number of `1`s at odd and even positions.

## Algorithm

1. Count the number of `1`s at even positions in `a`.
2. Count the number of `1`s at odd positions in `a`.
3. Do the same for `b`.
4. If both counts match, print `YES`.
5. Otherwise, print `NO`.

## Complexity

- Time: `O(n)`
- Space: `O(1)`

## Code
```
#include<bits/stdc++.h>
using namespace std;
int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);
int t;
cin>>t;
while(t--){
int n;
string a,b;
cin>>n>>a>>b;
int x[2]={},y[2]={};
for(int i=0;i<n;i++){
x[i%2]+=a[i]=='1';
y[i%2]+=b[i]=='1';
}
cout<<(x[0]==y[0]&&x[1]==y[1]?"YES\n":"NO\n");
}
}
```
