# 4. Marenol — Hard Version

## Problem

You are given two binary strings `a` and `b`.

Allowed operations:

`001 <-> 100`

`110 <-> 011`

Determine the minimum number of operations required to transform `a` into `b`.

If it is impossible, print `-1`.

## Key Observation

Every operation moves a `1` by exactly two positions.

Therefore parity is invariant:

- Odd-position `1`s remain odd-position `1`s.
- Even-position `1`s remain even-position `1`s.

First, the number of `1`s in each parity group must be equal.

Then match the `1`s in their original order.

If a `1` moves from position `x` to position `y`, it requires:

`|x-y| / 2`

operations.

Therefore:

`answer = sum(|positionA[i] - positionB[i]|) / 2`

for each parity group.

## Algorithm

1. Store positions of `1`s at even positions in `a`.
2. Store positions of `1`s at odd positions in `a`.
3. Do the same for `b`.
4. If the number of `1`s differs in either parity group, print `-1`.
5. Match corresponding `1`s inside each parity group.
6. Add the absolute differences of their positions.
7. Divide the total by `2`.
8. Print the result.

## Why Matching in Order Works

The `1`s cannot cross each other.

Therefore the first `1` in `a` must correspond to the first `1` in `b`, the second to the second, and so on.

This gives the minimum total movement.

## Complexity

- Time: `O(n)`
- Space: `O(n)`

## Code
```
#include<bits/stdc++.h>
using namespace std;
int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);
int t;
cin>>t;
while(t--){
int n;
string a,b;
cin>>n>>a>>b;
long long ans=0;
bool ok=true;
for(int p=0;p<2;p++){
vector<int>x,y;
for(int i=p;i<n;i+=2){
if(a[i]=='1')x.push_back(i);
if(b[i]=='1')y.push_back(i);
}
if(x.size()!=y.size()){
ok=false;
break;
}
for(int i=0;i<x.size();i++)
ans+=abs(x[i]-y[i]);
}
cout<<(ok?ans/2:-1)<<'\n';
}
}
```
