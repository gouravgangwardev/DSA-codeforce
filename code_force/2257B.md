# 1. Gigantomachy
## Problem

Two giants, Bea and Ver, each have a non-increasing sequence of mountain heights.

They attack each other's current mountain by reducing its height by `1`.

After each attack, a giant moves to the next mountain if the next mountain is exactly `1` higher than the current mountain.

Bea attacks first.

Determine which giant wins.

## Key Observation

Consider a mountain sequence:

`a1 >= a2 >= ... >= an`

To move from mountain `i` to mountain `i+1`, the current mountain must be reduced until:

`ai = ai+1 + 1`

Therefore, the number of attacks required to move from mountain `i` to `i+1` is:

`ai - ai+1 - 1`

After reaching the final mountain, it must be reduced completely.

So the total number of attacks required to defeat a giant with mountains:

`a1, a2, ..., an`

is:

`(a1-a2-1) + (a2-a3-1) + ... + (a(n-1)-an-1) + an`

Everything cancels:

`attacks = a1 - n + 1`

Therefore, only the height of the first mountain and the number of mountains matter.

For Bea:

`bea = b1 - m + 1`

because Bea must destroy Ver's mountains.

For Ver:

`ver = a1 - n + 1`

because Ver must destroy Bea's mountains.

Since Bea attacks first:

* If `bea <= ver`, Bea wins.
* Otherwise, Ver wins.

## Algorithm

1. Read `n`, `m`.

2. Read Bea's mountains.

3. Read Ver's mountains.

4. Calculate:

   `bea = b[0] - m + 1`

   `ver = a[0] - n + 1`

5. If `bea <= ver`, print `1`.

6. Otherwise, print `2`.

## Example

Suppose:

`a = [4,3,2,1]`

`b = [6,5]`

Bea needs:

`6 - 2 + 1 = 5`

attacks.

Ver needs:

`4 - 4 + 1 = 1`

attack.

Therefore Ver wins.

Answer:

`2`

## Complexity

* Time: `O(n + m)`
* Space: `O(n + m)`
